# ADR-0053 — Daily Brief: Regime + Research + Shadow Surfacing

**Status:** Accepted  
**Date:** 2026-05-27  
**Author:** Hermes Agent (v0.2-3)  
**Closes gap:** I5 from MoA review moa-review78-sonnet.md  

---

## Context

### The operator-feedback-loop gap

After Waves 7 and 8 shipped, an operator who wanted a complete morning view of
the system's state had to run **three separate CLI invocations**:

```
python scripts/quant-daily-interim.py           # picks + risk debate
python -c "from hermes_quant.regime.detector import ..."  # regime state
grep '"status": "running"' ~/.hermes/quant/research/hypotheses.jsonl  # active experiments
ls ~/.hermes/quant/shadow/*.db                  # shadow account P&L
```

The daily brief is the **one artifact the operator reads every morning** (on
Discord / Telegram).  Feature accessibility should not require separate script
invocations.  This ADR closes that gap by surfacing Wave 7/8 outputs directly
in the brief.

---

## Decision

Extend `scripts/quant-daily-interim.py` with three new subsections appended
**after** the existing per-pick block:

| Subsection | Emoji | Source | Wave |
|---|---|---|---|
| Market Regime | 🌡️ | `hermes_quant.regime` | 7 |
| Active Research | 🔬 | `~/.hermes/quant/research/hypotheses.jsonl` | 8a |
| Shadow Counterfactuals | 📊 | `~/.hermes/quant/shadow/*.db` | 8b |

Each subsection is generated by a dedicated `_compute_*_section()` function
that:
1. Reads materialised, on-disk artefacts (JSONL / SQLite).
2. Returns a **plain string** suitable for Discord/Telegram rendering.
3. Is wrapped in a `try/except` outer guard that catches **all exceptions** and
   returns a terse `(unavailable)` line — the brief itself never raises.

---

## Single-Pass Renderer Contract

The brief must remain **single-pass renderable**:

- **No async I/O.** All reads are synchronous file/SQLite reads.
- **No LLM calls.** The subsections read pre-computed artefacts only.
  The regime classifier runs deterministically from cached bar data.
- **No state mutation.** The brief is strictly read-only relative to the
  hermes-quant data stores.

This contract ensures the brief can be generated in a cron job with a
predictable and bounded execution time.

---

## Graceful-Degradation Pattern

Every `_compute_*_section()` follows this pattern:

```python
def _compute_foo_section() -> str:
    try:
        return _compute_foo_section_inner()
    except Exception as exc:
        return f"## Foo\n_(unavailable: {type(exc).__name__}: {exc})_\n"
```

The inner function may raise freely; the outer guard catches everything.
The three specific degradation cases and their expected output:

| Condition | Expected output |
|---|---|
| `hermes_quant.regime` not importable | `_(unavailable: …)_` |
| Regime cache (SPY bars) absent or corrupt | `_(unavailable: insufficient bars …)_` |
| `hypotheses.jsonl` missing | `_(no active research — use scripts/research-autopilot.py register …)_` |
| `hypotheses.jsonl` has no running rows | `_(no active research — …)_` |
| `~/.hermes/quant/shadow/` does not exist | `_(shadow accounts dormant — run scripts/shadow-replay-daily.py …)_` |
| Shadow `*.db` files exist but are empty / corrupt | `_(shadow accounts dormant — …)_` |

## Market Regime Subsection Design

The regime subsection computes `StateVariables` from SPY bars (broad market
proxy) and classifies via `RegimeDetector.classify()`.  SPY is fetched from
the yfinance cache that the advisor data layer already warms daily.

**Output (≤ 7 lines):**
```
## 🌡️ Market Regime

**🟢 BULL**
  vol(60d)=14.2%  pct=42%
  trend(z)=+0.74
  yield-curve(10y-2y)=+0.38%
  _trend_strength=0.740 >= 0.5 AND realized_vol_percentile=0.420 <= 0.6 → BULL_
```

---

## Active Research Subsection Design

Reads `hypotheses.jsonl` (append-only, ADR-0048).  The latest `status_change`
row per `hypothesis_id` wins.  Only `status="running"` rows are displayed.  Up
to 5 hypotheses are shown with:

- `hypothesis_id` (machine-readable, copy-pasteable)
- `claim` truncated to 80 chars
- Days since creation
- `related_adrs` (if set) shown inline in square brackets

**Output example (≤ 7 lines for 2 running hypotheses):**
```
## 🔬 Active Research

- `hyp_SPY_20260515_a3b9c1` (12d)  Sentiment analyst raises Sharpe >= 0.10 ov…  [ADR-0048]
- `hyp_QQQ_20260520_ff1234` (7d)   Regime-gated BMA reduces drawdown vs no-ga…
```

---

## Shadow Counterfactuals Subsection Design

Reads `shadow_pnl_history` from each `*.db` in `~/.hermes/quant/shadow/`.  The
most recent row per DB is used (ORDER BY asof DESC LIMIT 1).  Reports:

- Top 3 rules by all-time `pnl_total` (≥ 0)
- Top 1 underperformer (worst negative `pnl_total`)

The `pnl_total` column in `shadow_pnl_history` is the running delta vs the
account's `initial_cash` — it is not directly compared to production P&L, but
serves as a rank signal for which rules are generating counterfactual alpha.

**Output example:**
```
## 📊 Shadow Counterfactuals

**Top performers (all-time P&L vs production):**
  1. `aggressive_long` +$2,500
  2. `momentum_filter` +$800
**Underperformer:**
  ⚠️ `contrarian` $-300
```

## Backwards Compatibility

`format_brief()` receives the three sections as **optional keyword arguments**
(default `None`).  When all three are `None`, the brief is byte-identical to
the pre-ADR-0053 output.  Existing tests that call `format_brief()` without
these kwargs continue to pass.

---

## Alternatives Considered

### A — Separate `regime-summary.py` / `research-summary.py` scripts

Rejected: this is exactly the problem we are solving.  Adding more scripts
increases the gap, not closes it.

### B — Async reads with concurrent bar fetches

Rejected: breaks the single-pass renderer contract.  The brief is meant to be
a fast, predictable, cron-friendly script.  Async adds complexity and
unpredictable latency.

### C — Embed a full regime chart or Markdown table

Rejected: very-wide tables do not render well in Telegram/Discord.  Each
subsection is capped at ~5-10 lines using newline-delimited rows and short
labels.

---

## Consequences

### Positive

- Operator sees regime state, active experiments, and shadow P&L in the same
  morning read they already do.
- Zero new hard dependencies: subsections degrade gracefully when Wave 7/8
  infrastructure is absent.
- Closes MoA review I5.

### Negative / Trade-offs

- Brief length increases by ≤ 30 lines on a fully-populated install.
- Regime computation adds a `yfinance.download("SPY", ...)` call on a cold
  cache; this is bounded by network latency (~1-3s) and is non-blocking to
  the picks section.
