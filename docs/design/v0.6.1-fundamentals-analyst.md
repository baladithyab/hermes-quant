## 0. Executive summary

TauricResearch G4 — that an equities trader with **zero balance-sheet / income-
statement / cashflow input is structurally lobotomized** — is the operative
gap. We close it by adding a fifth analyst, `FundamentalsAnalyst`, that fans
in via the existing `Analyst` Protocol (ADR-0002 / `protocol.py:417`), is
weighted by the BMA aggregator like every other analyst, and **NEVER trains,
only infers** (per ADR-0018 §D8 charter, generalized).

Three load-bearing design choices distinguish this analyst from the four
already shipped (ClassicalTA, Microstructure, Kronos, Semantic):

1. **Slow fundamentals refresh.** Fundamentals change quarterly, not per-tick.
   We snapshot per `(ticker, as_of_date)` to a parquet cache and the analyst
   calls into the cache, never directly into yfinance, on the hot path.
2. **Asset-class hard gate.** Crypto and FX have no income statement; ETFs
   have a synthetic one that doesn't mean what `info["trailingPE"]` claims.
   `_classify_symbol_universe` returns one of `{equity, etf, crypto, fx,
   unknown}` and only `equity` proceeds; everything else returns `None`
   (Protocol-clean abstain), not a zero-confidence view (which would still
   bump the silence-bias gate's emitted-count and is therefore unsafe per
   ADR-0018 §D4 footgun discussion).
3. **Per-signal calibration table.** Six signals with wildly different units
   (P/E in 5–100×, debt/equity in 0–5×, margin in % points). Each signal
   has its own raw-confidence function, and the composite is the
   agreement-weighted mean clipped at `[0.30, 0.85]` (same envelope as
   Kronos for the same reason: foundation-data-overconfidence guard).

**yfinance vs SEC EDGAR:** yfinance is *adequate for v0.6.1*. SEC EDGAR is
the audit-grade ground truth and is desirable but is deferred to v0.7 (see
§D9 Alternatives). yfinance's failure modes (stale fields, unit confusion
between cents/dollars, missing sector benchmarks for thinly-covered names)
are bounded by per-signal sanity gates that abstain rather than emit garbage.

## 1. ADR-0064 draft — FundamentalsAnalyst integration

> **ADR-0064: FundamentalsAnalyst — fifth voice, equity-only, snapshot-cached**
>
> **Status:** Proposed
> **Date:** 2026-05-27
> **Target:** v0.6.1
> **Cross-cuts:** ADR-0002 (Analyst Protocol), ADR-0003 (BMA aggregator), ADR-0005 (Data layer / yfinance), ADR-0018 (Kronos — pattern template), ADR-0036 (Multi-horizon), founding charter §"trader without fundamentals is lobotomized" (TauricResearch G4)
> **Research:** TauricResearch/TradingAgents `tradingagents/agents/analysts/fundamentals_analyst.py`, `tradingagents/dataflows/y_finance.py` (DeepWiki query 2026-05-27)

### 1.1 Context

The four existing analysts cover:
| Analyst | Asset classes | Signal type |
|---|---|---|
| ClassicalTA | crypto/equity/etf/fx | Price-momentum / oscillators |
| MicrostructureLite | crypto/equity (intraday) | Order-flow / spread |
| Kronos | crypto/equity/etf | Foundation-model OHLCV forecast |
| Semantic | all | LLM perception layer |

All four read from price/volume/orderbook/news. **None reads the issuer's
actual financial statements.** For an equity trader this is the largest
single information gap: the BMA committee can have unanimous TA + Kronos
agreement on a long while the issuer is bleeding cash and tripping debt
covenants. The aggregator has no way to know.

The TauricResearch reference implementation's `FundamentalsAnalyst` reads
six metrics off `yfinance.Ticker.info` (TTM P/E, Forward PE, Debt/Equity,
FCF, Revenue TTM, EPS TTM/Forward) and writes them into the agent's prompt.
We adapt the *signals*, not the LLM-prompted form: a deterministic analyst
emitting a typed `AnalystView` is the only shape compatible with our BMA
ensemble.

### 1.2 Decision

#### D1: One voice, weighted by BMA like every other analyst

Per ADR-0018 §D1: the aggregator does not know FundamentalsAnalyst exists.
It receives an `AnalystView` with `(direction, magnitude, confidence,
horizon, metadata)`. If FundamentalsAnalyst's calibrator (per ADR-0010)
shows it underperforms in a given regime, BMA downweights it. Charter
"one analyst, not the oracle" is preserved by construction.

#### D2: Six signals, three-of-six minimum, agreement-weighted composite

The analyst computes up to six sub-signals (see §2 schema). Composite logic
mirrors `ClassicalTAAnalyst.analyze`:

- Each sub-signal emits `(direction ∈ {-1,0,1}, magnitude_pct, raw_conf,
  label)`.
- Sub-signals with `direction == 0` are dropped (insufficient data, near-
  median value, or hard sanity-gate failure).
- If **fewer than 3 of 6** sub-signals survive, the analyst returns
  `None` — partial-data abstain. (Three-of-six threshold rationale: with
  two signals you're a coin flip; with three you have at least one source
  of independent information per the three balance-sheet/income/
  cashflow categories.)
- If surviving signals tie 50/50, return `None` (silence-by-default).
- Otherwise composite direction = plurality, magnitude = mean of
  contributing magnitudes, raw_conf = `(n_contributing / n_surviving) *
  mean(sub_conf)`.

#### D3: Confidence clipping

```python
RAW_CONFIDENCE_CLIP = (0.20, 0.80)
```

Floor 0.20 (looser than Kronos 0.30 because partial-data is less obviously
wrong than path-disagreement); ceiling 0.80 (tighter than ClassicalTA's
implicit 1.0 because yfinance values can be wrong without warning).

The BMA aggregator's calibrator further shrinks; this clip is the analyst-
local guard against unanimous agreement over six gameable proxy metrics.

#### D4: Equity-only by hard symbol-class gate

```python
def _classify_symbol_universe(asset: str, asset_class: str | None) -> str:
    """Returns one of: 'equity', 'etf', 'crypto', 'fx', 'unknown'."""
```

Decision rules, in order:
1. If `asset_class` (from MarketContext) is set, trust it.
2. Else if `/` in asset → 'crypto' (e.g. `"BTC/USDT"`).
3. Else if `=X` suffix → 'fx' (yfinance FX convention, e.g. `"EURUSD=X"`).
4. Else if asset matches a curated ETF list (or yfinance `info["quoteType"]
   == "ETF"`) → 'etf'.
5. Else → 'equity'.
6. Empty / non-string → 'unknown'.

Only `'equity'` proceeds. Everything else → `return None` (Protocol-clean
abstain, NOT a zero-confidence view — an unsupported asset class is not the
same condition as "I tried and have nothing useful to say"; it's "this
question is not for me", which the silence-bias gate's emitted-count must
not see).

#### D5: Snapshot cache, not per-tick fetch

Fundamentals change quarterly. yfinance is rate-limited and slow (~1–3s
per `Ticker.info` call). Per-tick fetch is wrong on both axes.

Cache layout:

```
~/.hermes/quant/cache/fundamentals/
    yfinance/
        AAPL.parquet                 # one row per as_of_date snapshot
        MSFT.parquet
        ...
    sec_edgar/                       # reserved for v0.7
```

Schema (one parquet file per ticker, append-only):

| column | dtype | source |
|---|---|---|
| `as_of_date` | date | snapshot key (UTC, day-truncated) |
| `fetched_at` | datetime[ns, UTC] | wall-clock fetch time |
| `source` | str | `"yfinance"` / `"yfinance_balance_sheet"` |
| `pe_trailing` | float64 | `info["trailingPE"]` |
| `pe_forward` | float64 | `info["forwardPE"]` |
| `debt_to_equity` | float64 | `info["debtToEquity"] / 100` (yfinance scales) |
| `free_cash_flow` | float64 | `info["freeCashflow"]` |
| `revenue_ttm` | float64 | `info["totalRevenue"]` |
| `eps_trailing` | float64 | `info["trailingEps"]` |
| `eps_forward` | float64 | `info["forwardEps"]` |
| `gross_margin_ttm` | float64 | derived from income_stmt |
| `revenue_yoy` | float64 | derived from quarterly income_stmt |
| `sector` | str | `info["sector"]` |
| `currency` | str | `info["currency"]` |
| `quote_type` | str | `info["quoteType"]` |
| `raw_info_json` | str | full `info` dict, json.dumps, capped at 4 KiB |

Invalidation: TTL of 24 hours per ticker. A stale row triggers a refetch on
the next analyzer call AND the analyst still uses the stale row in the
meantime (graceful degradation — fundamentals 24h old are still better than
none).

Sector-median benchmarks live in a sibling `~/.hermes/quant/cache/
fundamentals/sector_medians.parquet`, refreshed weekly via a separate cron
(`hermes-quant.cron.fundamentals-sector-refresh`, scheduled weekly). The
analyst reads sector medians but never writes them. If sector_medians.parquet
is missing or older than 30 days, sector-relative signals (`_score_pe_ratio`)
abstain individually (raw_conf = 0); other signals proceed.

#### D6: Per-signal raw-confidence calibration table

| Signal | Predicate | direction | raw_conf |
|---|---|---|---|
| **`pe_relative`** | `pe_ttm < sector_median * 0.7` | +1 (cheap) | 0.80 |
|  | `pe_ttm < sector_median * 0.85` | +1 | 0.55 |
|  | `pe_ttm > sector_median * 1.15` | −1 | 0.55 |
|  | `pe_ttm > sector_median * 1.30` | −1 (rich) | 0.80 |
|  | else | 0 | 0.0 |
|  | `pe_ttm <= 0` (loss-making) | 0 | 0.0 (abstain — handled by FCF) |
| **`debt_equity_trend`** | `dte < 0.3` | +1 (clean) | 0.50 |
|  | `dte > 2.0` | −1 (highly levered) | 0.70 |
|  | `dte > 5.0` | −1 (covenant-risk) | 0.85 |
|  | else | 0 | 0.0 |
| **`fcf_per_share_growth`** | `fcf_yoy > +0.20` | +1 | 0.65 |
|  | `fcf_yoy < −0.20` | −1 | 0.65 |
|  | `fcf < 0` last quarter | −1 (cash-burning) | 0.55 |
|  | else | 0 | 0.0 |
| **`revenue_yoy`** | `rev_yoy > +0.15` | +1 | 0.55 |
|  | `rev_yoy < 0.0` | −1 | 0.60 |
|  | `rev_yoy < −0.10` | −1 (declining) | 0.75 |
|  | else | 0 | 0.0 |
| **`earnings_surprise`** | `actual > consensus * 1.05` | +1 | 0.60 |
|  | `actual < consensus * 0.95` | −1 | 0.65 |
|  | else | 0 | 0.0 |
|  | (consensus missing) | 0 | 0.0 (abstain) |
| **`gross_margin_trend`** | `gm_now > gm_prior + 200 bps` | +1 | 0.50 |
|  | `gm_now < gm_prior − 200 bps` | −1 | 0.55 |
|  | else | 0 | 0.0 |

All `raw_conf` values are derived from a **prior-shrinkage Bayesian** view:
calibration ground truth comes from BMA's `update_calibrator` loop over
realized fills; until 200 outcomes accumulate, the table is the warm-start.
Numbers are conservative on purpose — see §1.4 Consequences.

Magnitudes are uniformly mapped from the **horizon-1d / 1w / 1M** equity
volatility envelopes:

| Horizon | Magnitude (signed return frac) |
|---|---|
| `1d` | 0.005 (50 bps — fundamentals don't move price intraday) |
| `1w` | 0.015 |
| `1M` | 0.040 |
| `1Q` | 0.080 |

Default `horizon = "1M"` (fundamentals' natural revaluation timescale).

#### D7: Latency: daily-cached, per-tick read-only

The analyst's hot path is parquet read + arithmetic. ~5–20ms per call.
Refresh is deferred to a background cron (`hermes-quant.cron.fundamentals-
refresh`, scheduled daily 03:00 UTC) which iterates the watchlist and
writes one parquet append per ticker. If the cron fails the analyst keeps
serving stale data; if the data is >7 days old per-signal sanity gates
trip and the analyst abstains.

This is a deliberate departure from Kronos's lazy-load (which loads weights
on first call). Fundamentals are tabular and sharable across symbols within
a quarterly cycle, so amortizing the fetch into a cron is strictly cheaper.

#### D8: NEVER trains, only infers (per ADR-0018 §D8 generalized)

The analyst is **stateless across calls** beyond the disk cache. There is
no `update()` method that mutates internal state from outcomes; the
calibrator-from-fills hook is forwarded to `self.calibrator.fit(...)`
exactly like ClassicalTA / Kronos. Re-tuning the per-signal calibration
table is a *manual* quarterly review (charter "PPO or recurrent SAC for
the aggregator, with the analyst pool frozen"), not a learned online update.

#### D9: yfinance is the v0.6.1 source; SEC EDGAR is reserved

We use yfinance because:
- Already wired in the data layer (ADR-0005).
- Provides the six metrics in one `Ticker.info` call.
- Batch DataFrame access via `.balance_sheet / .income_stmt / .cashflow`.
- Crypto/ETF detection via `info["quoteType"]` is free.

Known yfinance failure modes and their mitigations:

| Failure | Mitigation |
|---|---|
| Field missing for thinly-covered ticker | Per-signal abstain (raw_conf = 0); composite needs ≥3 surviving |
| Cents/dollars unit confusion (rare, observed on ADRs) | `_sanity_clip_pe`: reject \|P/E\| > 1000, \|D/E\| > 50, FCF outside ±$1T |
| Stale `info` dict (yfinance scrapes infrequently) | TTL 24h; per-signal staleness gate at >7d |
| Sector unknown / `info["sector"] == "—"` | `pe_relative` abstains (no benchmark); other signals proceed |
| Foreign-currency revenue (e.g. `info["currency"] == "JPY"`) | Currency-neutral signals (P/E, D/E, margins) proceed; absolute FCF gated to USD-only |

SEC EDGAR (Form 10-Q / 10-K XBRL) is the audit-stamped ground truth and
should land in v0.7. Deferral rationale: the EDGAR XBRL parser is a
multi-week build (filing format heterogeneity 2003–present, restatement
handling, segment reporting) and the marginal accuracy gain over yfinance
on the six chosen metrics is small (<5% on liquid US large-caps).

### 1.4 Consequences

**Positive:**
- Closes TauricResearch G4 — equity trader now has fundamentals input.
- Charter "one analyst, not the oracle" preserved — analyst joins BMA committee on equal footing.
- Slow refresh + parquet cache → near-zero per-tick latency cost.
- Deterministic per-signal calibration table → backtestable, replayable, no LLM in the hot path.

**Negative:**
- yfinance fragility transferred into the analyst (mitigated by sanity-gates and per-signal abstain).
- Sector-median benchmark requires a separate weekly cron and 30-day staleness handling.
- 12-month track record needed before BMA's calibrator-from-fills can meaningfully reweight the analyst — same cold-start as every other analyst.
- Six sub-signals × per-signal calibration table = surface area for bugs; mitigated by per-signal unit tests + a frozen "golden snapshot" parquet for AAPL on a known date used in regression tests.

### 1.5 Migration

No breaking changes. `FundamentalsAnalyst` is added to `_default_analysts()`
behind an opt-out env var:

```bash
# Default: analyst loaded
HERMES_QUANT_FUNDAMENTALS_ANALYST=1   # opt-in (default in v0.6.1)
HERMES_QUANT_FUNDAMENTALS_ANALYST=0   # opt-out
```

Legacy operators on offline boxes (no internet → no yfinance → no fetches)
get clean abstains via D5 staleness gate; no exception propagates.

See §6 below — 12 unit tests + 2 backtest ablations.

## 2. Class skeleton

File: `hermes_quant/analysts/fundamentals.py`

```python
"""hermes_quant.analysts.fundamentals — equity fundamentals analyst.

Per ADR-0064: emits one AnalystView combining six sub-signals derived
from yfinance .info / .balance_sheet / .income_stmt / .cashflow.
Equity-only; abstains (returns None) for ETF / crypto / FX. NEVER
trains, only infers (ADR-0018 §D8 generalized).
"""

from __future__ import annotations

import logging
from dataclasses import dataclass
from pathlib import Path
from typing import Literal

import numpy as np
import pandas as pd

from hermes_quant.calibrators import ColdStartCalibrator
from hermes_quant.data.fundamentals_provider import FundamentalsProvider
from hermes_quant.protocol import (
    AnalystView,
    CalibratorNotReady,
    Direction,
    MarketContext,
    RealizedOutcome,
)

logger = logging.getLogger(__name__)


SymbolUniverse = Literal["equity", "etf", "crypto", "fx", "unknown"]


@dataclass
class _SubSignal:
    direction: Direction
    magnitude: float
    raw_confidence: float
    label: str
    rationale: str = ""


class FundamentalsAnalyst:
    """Six-signal fundamentals analyst (P/E, D/E, FCF growth, revenue YoY,
    earnings surprise, gross-margin trend).

    Per ADR-0064:
      - Equity-only (hard gate via _classify_symbol_universe).
      - Reads from FundamentalsProvider's parquet cache (no live yfinance
        in hot path).
      - Six sub-signals, ≥3 surviving for composite, plurality direction.
      - Raw confidence clipped to [0.20, 0.80].
      - Default horizon = "1M".

    Discoverable via [project.entry-points."hermes_quant.analysts"]
    = "fundamentals".
    """

    name = "fundamentals"
    timeframes = ["1d", "1w", "1M", "1Q"]
    asset_classes = ["equity"]  # ETF/crypto/FX abstain via Protocol-None
    enabled = True

    SUB_SIGNAL_LABELS = (
        "pe_relative",
        "debt_equity_trend",
        "fcf_per_share_growth",
        "revenue_yoy",
        "earnings_surprise",
        "gross_margin_trend",
    )

    # Per-horizon magnitude envelope (ADR-0064 §D6 table)
    _MAGNITUDE_BY_HORIZON: dict[str, float] = {
        "1d": 0.005, "1w": 0.015, "1M": 0.040, "1Q": 0.080,
    }

    # Confidence-clip envelope (ADR-0064 §D3)
    _RAW_CONF_CLIP_LO = 0.20
    _RAW_CONF_CLIP_HI = 0.80

    # Composite gates
    _MIN_SURVIVING_SUBSIGNALS = 3
    _STALENESS_DAYS_HARD_LIMIT = 7  # per-signal abstain if older

    def __init__(
        self,
        *,
        horizon: str = "1M",
        provider: FundamentalsProvider | None = None,
        cache_root: Path | None = None,
        # Test seam
        _now_factory=None,
    ):
        self.horizon = horizon
        self.provider = provider or FundamentalsProvider(
            cache_root=cache_root or Path.home() / ".hermes" / "quant" / "cache" / "fundamentals"
        )
        self.calibrator = ColdStartCalibrator()
        self._now = _now_factory or (lambda: pd.Timestamp.now(tz="UTC"))

        self._n_views_emitted = 0
        self._last_view_at: pd.Timestamp | None = None
        self._error_count = 0

    # ------------------------------------------------------------------
    # Symbol-class classification
    # ------------------------------------------------------------------

    @staticmethod
    def _classify_symbol_universe(
        asset: str, asset_class: str | None
    ) -> SymbolUniverse:
        """ADR-0064 §D4 routing rule."""
        if not asset or not isinstance(asset, str):
            return "unknown"
        if asset_class in ("equity", "etf", "crypto", "fx", "option"):
            # Trust MarketContext if upstream populated it.
            if asset_class == "option":
                return "unknown"
            return asset_class  # type: ignore[return-value]
        if "/" in asset:
            return "crypto"
        if asset.endswith("=X"):
            return "fx"
        # Conservative default: treat as equity. ETF detection via
        # provider's .info["quoteType"] handled in _fetch_fundamentals.
        return "equity"

    # ------------------------------------------------------------------
    # Cache-backed fetch
    # ------------------------------------------------------------------

    def _fetch_fundamentals(
        self, ticker: str, asof: pd.Timestamp
    ) -> pd.Series | None:
        """Read latest snapshot from the parquet cache. Returns None if
        no snapshot exists OR the snapshot is older than the staleness
        hard limit (7 days for v0.6.1; tightens to 24h once cron is
        stable).

        Provider.refresh_if_stale is a NO-OP on the hot path — the cron
        does the writes. The hot path is parquet-read only.
        """
        try:
            snapshot = self.provider.read_latest(ticker, as_of=asof)
        except FileNotFoundError:
            return None
        except Exception as exc:  # noqa: BLE001
            logger.debug("fundamentals: cache read failed for %s: %s", ticker, exc)
            return None
        if snapshot is None:
            return None
        # ETF/quoteType post-check: yfinance sometimes labels ETFs that
        # got past the heuristic gate above.
        if snapshot.get("quote_type", "").upper() == "ETF":
            return None
        age_days = (asof - pd.Timestamp(snapshot["fetched_at"]).tz_convert("UTC")).days
        if age_days > self._STALENESS_DAYS_HARD_LIMIT:
            return None
        return snapshot

    # ------------------------------------------------------------------
    # Sub-signal scorers (one per signal in the calibration table)
    # ------------------------------------------------------------------

    def _score_pe_ratio(
        self, snap: pd.Series, sector_median_pe: float | None
    ) -> _SubSignal:
        pe = snap.get("pe_trailing")
        if pe is None or np.isnan(pe) or pe <= 0:
            return _SubSignal(0, 0.0, 0.0, "pe_relative", "missing or non-positive")
        if not (0 < pe < 1000):  # sanity gate
            return _SubSignal(0, 0.0, 0.0, "pe_relative", "out of sane range")
        if sector_median_pe is None or sector_median_pe <= 0:
            return _SubSignal(0, 0.0, 0.0, "pe_relative", "no sector benchmark")
        ratio = pe / sector_median_pe
        if ratio < 0.7:
            return _SubSignal(+1, self._mag(), 0.80, "pe_relative",
                              f"P/E={pe:.1f} vs sector {sector_median_pe:.1f} → cheap")
        if ratio < 0.85:
            return _SubSignal(+1, self._mag() * 0.7, 0.55, "pe_relative",
                              f"P/E={pe:.1f} vs sector {sector_median_pe:.1f}")
        if ratio > 1.30:
            return _SubSignal(-1, self._mag(), 0.80, "pe_relative",
                              f"P/E={pe:.1f} vs sector {sector_median_pe:.1f} → rich")
        if ratio > 1.15:
            return _SubSignal(-1, self._mag() * 0.7, 0.55, "pe_relative",
                              f"P/E={pe:.1f} vs sector {sector_median_pe:.1f}")
        return _SubSignal(0, 0.0, 0.0, "pe_relative", "near sector median")

    def _score_debt_equity(self, snap: pd.Series) -> _SubSignal:
        dte = snap.get("debt_to_equity")
        if dte is None or np.isnan(dte) or dte < 0:
            return _SubSignal(0, 0.0, 0.0, "debt_equity_trend", "missing")
        if dte > 50:  # sanity
            return _SubSignal(0, 0.0, 0.0, "debt_equity_trend", "out of sane range")
        if dte < 0.3:
            return _SubSignal(+1, self._mag() * 0.6, 0.50, "debt_equity_trend",
                              f"D/E={dte:.2f} → clean balance sheet")
        if dte > 5.0:
            return _SubSignal(-1, self._mag(), 0.85, "debt_equity_trend",
                              f"D/E={dte:.2f} → covenant risk")
        if dte > 2.0:
            return _SubSignal(-1, self._mag() * 0.7, 0.70, "debt_equity_trend",
                              f"D/E={dte:.2f} → highly levered")
        return _SubSignal(0, 0.0, 0.0, "debt_equity_trend", "moderate leverage")

    def _score_fcf_growth(self, snap: pd.Series) -> _SubSignal:
        fcf = snap.get("free_cash_flow")
        fcf_yoy = snap.get("fcf_yoy")  # populated by provider
        if fcf is None or np.isnan(fcf):
            return _SubSignal(0, 0.0, 0.0, "fcf_per_share_growth", "missing")
        if fcf < 0:
            return _SubSignal(-1, self._mag() * 0.6, 0.55, "fcf_per_share_growth",
                              f"FCF={fcf:.2e} → cash-burning")
        if fcf_yoy is None or np.isnan(fcf_yoy):
            return _SubSignal(0, 0.0, 0.0, "fcf_per_share_growth", "no YoY")
        if fcf_yoy > 0.20:
            return _SubSignal(+1, self._mag() * 0.8, 0.65, "fcf_per_share_growth",
                              f"FCF YoY +{fcf_yoy:.1%}")
        if fcf_yoy < -0.20:
            return _SubSignal(-1, self._mag() * 0.8, 0.65, "fcf_per_share_growth",
                              f"FCF YoY {fcf_yoy:.1%}")
        return _SubSignal(0, 0.0, 0.0, "fcf_per_share_growth", "stable")

    def _score_revenue_yoy(self, snap: pd.Series) -> _SubSignal:
        ryoy = snap.get("revenue_yoy")
        if ryoy is None or np.isnan(ryoy):
            return _SubSignal(0, 0.0, 0.0, "revenue_yoy", "missing")
        if ryoy > 0.15:
            return _SubSignal(+1, self._mag() * 0.7, 0.55, "revenue_yoy",
                              f"Rev YoY +{ryoy:.1%}")
        if ryoy < -0.10:
            return _SubSignal(-1, self._mag() * 0.9, 0.75, "revenue_yoy",
                              f"Rev YoY {ryoy:.1%} → declining")
        if ryoy < 0.0:
            return _SubSignal(-1, self._mag() * 0.7, 0.60, "revenue_yoy",
                              f"Rev YoY {ryoy:.1%}")
        return _SubSignal(0, 0.0, 0.0, "revenue_yoy", "flat")

    def _score_earnings_surprise(self, snap: pd.Series) -> _SubSignal:
        actual = snap.get("eps_trailing")
        consensus = snap.get("eps_forward")  # proxy: consensus next-Q
        if actual is None or consensus is None or np.isnan(actual) or np.isnan(consensus):
            return _SubSignal(0, 0.0, 0.0, "earnings_surprise", "missing")
        if consensus <= 0:
            return _SubSignal(0, 0.0, 0.0, "earnings_surprise", "consensus <= 0")
        ratio = actual / consensus
        if ratio > 1.05:
            return _SubSignal(+1, self._mag() * 0.7, 0.60, "earnings_surprise",
                              f"actual ${actual:.2f} vs consensus ${consensus:.2f} (+{ratio-1:.1%})")
        if ratio < 0.95:
            return _SubSignal(-1, self._mag() * 0.8, 0.65, "earnings_surprise",
                              f"actual ${actual:.2f} vs consensus ${consensus:.2f} ({ratio-1:.1%})")
        return _SubSignal(0, 0.0, 0.0, "earnings_surprise", "in line")

    def _score_gross_margin(self, snap: pd.Series) -> _SubSignal:
        gm_now = snap.get("gross_margin_ttm")
        gm_prior = snap.get("gross_margin_prior")  # provider populates from y-1
        if gm_now is None or gm_prior is None or np.isnan(gm_now) or np.isnan(gm_prior):
            return _SubSignal(0, 0.0, 0.0, "gross_margin_trend", "missing")
        delta_bps = (gm_now - gm_prior) * 10_000
        if delta_bps > 200:
            return _SubSignal(+1, self._mag() * 0.6, 0.50, "gross_margin_trend",
                              f"GM Δ +{delta_bps:.0f}bps")
        if delta_bps < -200:
            return _SubSignal(-1, self._mag() * 0.7, 0.55, "gross_margin_trend",
                              f"GM Δ {delta_bps:.0f}bps")
        return _SubSignal(0, 0.0, 0.0, "gross_margin_trend", "stable")

    def _mag(self) -> float:
        """Per-horizon magnitude envelope."""
        return self._MAGNITUDE_BY_HORIZON.get(self.horizon, 0.040)

    # ------------------------------------------------------------------
    # Public API (Analyst Protocol)
    # ------------------------------------------------------------------

    def analyze(self, ctx: MarketContext) -> AnalystView | None:
        """Per ADR-0002 + ADR-0064.

        Returns None when:
          - asset class is not 'equity'
          - cache miss / staleness hard limit
          - <3 surviving sub-signals (partial-data abstain)
          - tied composite (silence-by-default)
        """
        try:
            uni = self._classify_symbol_universe(ctx.asset, ctx.asset_class)
            if uni != "equity":
                return None

            snap = self._fetch_fundamentals(ctx.asset, ctx.asof)
            if snap is None:
                return None

            sector_median_pe = self.provider.read_sector_median_pe(
                snap.get("sector"), as_of=ctx.asof
            )

            sub_signals = [
                self._score_pe_ratio(snap, sector_median_pe),
                self._score_debt_equity(snap),
                self._score_fcf_growth(snap),
                self._score_revenue_yoy(snap),
                self._score_earnings_surprise(snap),
                self._score_gross_margin(snap),
            ]

            surviving = [s for s in sub_signals if s.direction != 0]
            if len(surviving) < self._MIN_SURVIVING_SUBSIGNALS:
                return None

            longs = [s for s in surviving if s.direction == +1]
            shorts = [s for s in surviving if s.direction == -1]
            if len(longs) > len(shorts):
                composite_dir: Direction = +1
                contributing = longs
            elif len(shorts) > len(longs):
                composite_dir = -1
                contributing = shorts
            else:
                return None  # tie → silence

            magnitude = float(np.mean([s.magnitude for s in contributing]))
            agreement = len(contributing) / len(surviving)
            mean_conf = float(np.mean([s.raw_confidence for s in contributing]))
            confidence_raw = float(np.clip(
                agreement * mean_conf,
                self._RAW_CONF_CLIP_LO,
                self._RAW_CONF_CLIP_HI,
            ))

            try:
                calibrated = self.calibrator.calibrate(confidence_raw)
            except CalibratorNotReady:
                # Match ClassicalTA's Beta(α=2,β=5) warm-start
                calibrated = (confidence_raw + 2.0) / 8.0

            view = AnalystView(
                analyst=self.name,
                direction=composite_dir,
                magnitude=magnitude,
                confidence=calibrated,
                confidence_raw=confidence_raw,
                horizon=self.horizon,
                rationale=(
                    f"agreement={len(contributing)}/{len(surviving)} surviving "
                    f"({','.join(s.label for s in contributing)})"
                ),
                metadata={
                    "snapshot_age_days": int(
                        (ctx.asof - pd.Timestamp(snap["fetched_at"]).tz_convert("UTC")).days
                    ),
                    "sector": snap.get("sector"),
                    "sub_signals": [
                        {
                            "label": s.label,
                            "direction": s.direction,
                            "magnitude": s.magnitude,
                            "raw_conf": s.raw_confidence,
                            "rationale": s.rationale,
                        }
                        for s in sub_signals
                    ],
                },
            )
            self._n_views_emitted += 1
            self._last_view_at = ctx.asof
            return view

        except Exception as exc:  # noqa: BLE001
            self._error_count += 1
            logger.exception("fundamentals analyze failed: %s", exc)
            return None

    def update(self, outcome: RealizedOutcome) -> None:
        """ADR-0010 calibrator-from-fills hook. NEVER mutates analyst
        weights — only the calibrator. Per ADR-0018 §D8 generalized."""
        self.calibrator.fit(
            [outcome.view.confidence_raw], [outcome.direction_correct]
        )

    def health(self) -> dict:
        return {
            "name": self.name,
            "n_views_emitted": self._n_views_emitted,
            "last_view_at": self._last_view_at.isoformat() if self._last_view_at else None,
            "error_count": self._error_count,
            "calibrator_status": self.calibrator.status(),
            "horizon": self.horizon,
            "cache_root": str(self.provider.cache_root),
        }
```

## 4. Cache design

**Location:** `~/.hermes/quant/cache/fundamentals/yfinance/<TICKER>.parquet`

**Per-ticker schema:** (one row per `as_of_date` snapshot — see ADR §1.2 D5
table)

**Append discipline:** mirror `OhlcvCache.write` from `hermes_quant/data/cache.py:76`:
1. Read existing parquet (if any) into DataFrame.
2. Append new row.
3. Dedupe on `as_of_date` (keep the row with the latest `fetched_at`).
4. Write to a temp file in the same directory.
5. `os.replace(tmp_path, parquet_path)` for atomicity.

**Invalidation policies:**

| Scope | TTL | Action on stale |
|---|---|---|
| Per-ticker snapshot | 24h | Cron refresh fetches new row; analyst keeps reading prior row |
| Per-ticker hard staleness | 7d | Analyst returns None for that ticker until cron succeeds |
| Sector medians | 7d soft / 30d hard | Soft: cron refreshes; Hard: pe_relative abstains, others proceed |

**Rationale for parquet over CSV:** existing `OhlcvCache` already prefers
parquet; consistency. Float64 fidelity matters more here than for OHLCV
(P/E and margins have meaningful sub-decimal precision).

**Disk footprint:** ~500 bytes/row × 1 row/quarter × 5y history × S&P 500
= ~2.5 MB total. Negligible.

## 5. Abstain semantics

| Condition | Behavior | Rationale |
|---|---|---|
| `asset_class ∉ {"equity"}` (incl. ETF, crypto, FX) | `return None` | Question not for me; silence-bias gate must NOT count this |
| `quote_type == "ETF"` discovered after fetch | `return None` | Same as above; ETF synthetic fundamentals are misleading |
| Cache miss, no parquet for ticker | `return None` | First-tick on a new symbol; cron will populate |
| Cache row > 7 days old | `return None` | Stale fundamentals are worse than no fundamentals |
| <3 sub-signals survive their per-signal gates | `return None` | Partial-data abstain |
| Surviving signals tie 50/50 | `return None` | Silence-by-default |
| `analyze()` raises | `error_count++; return None` | Same as ClassicalTA — one bad ticker can't kill the analyst |
| Sector benchmark missing | Per-signal abstain (raw_conf=0); composite proceeds | pe_relative is one of six; the other five carry on |
| yfinance returns nan in field | Per-signal abstain | Field-level granularity |

**Critical contrast to Kronos:** Kronos returns a *zero-confidence
AnalystView* on weight-load failure (so it stays "registered" without
polluting silence-bias). FundamentalsAnalyst returns *None* on asset-class
mismatch. The difference is that Kronos's failure is conditional/transient
("weights couldn't load this minute"), while ours is structural ("this
asset has no balance sheet, ever"). Returning a view here would be lying.

## 7. ADR-0018 §D8 charter compliance check

> *"PPO or recurrent SAC for the aggregator, with the analyst pool frozen
> most of the time. Re-train analysts on a slow cycle (monthly/quarterly)
> on actual realized data."* — ADR-0018 §D8 / charter §"What works"

**FundamentalsAnalyst respects this clause:**

1. **No `analyze()` mutation of internal state beyond counters.** The
   per-signal calibration table (§D6) is class-level constants; nothing
   in `analyze()` rewrites them.
2. **`update(outcome)` forwards to `self.calibrator.fit()` only.** The
   calibrator is the *aggregator-side* calibrator-from-fills mechanism
   (ADR-0010), not analyst-side reweighting.
3. **Per-signal table revisions are manual, quarterly.** Documented in the
   ADR §1.5 Migration / §1.4 Consequences. There is no online-learning
   path that mutates the table.
4. **No model weights to retrain.** Unlike Kronos, this analyst has no
   neural net; the calibration table is the only "model" and it's
   deterministic.

✅ Charter clause honored.

## 8. Open questions / risks

1. **Earnings-surprise proxy.** We use `eps_forward` as consensus proxy
   because yfinance doesn't expose I/B/E/S consensus directly. This
   conflates "next-Q forecast" with "consensus on the just-reported Q".
   v0.7 SEC EDGAR work should add proper EPS-actual vs consensus once we
   wire a consensus source (Alpha Vantage / FMP).
2. **Sector classification.** GICS sector via yfinance `info["sector"]`
   is inconsistent (sometimes reports "Industry" granularity). The
   sector-medians cron normalizes to 11 GICS sectors; ambiguous mappings
   default to "Industrials" (largest bucket).
3. **Currency normalization.** Foreign-listed ADRs (e.g. TSM) report in
   USD via `info["currency"]`, but Japanese ADRs occasionally report in
   JPY for absolute-FCF fields. The sanity gates catch egregious cases;
   per-currency normalization is v0.7.
4. **Earnings season concentration.** All US large-caps report within a
   3-week window each quarter; the cron must handle the burst (~500
   tickers in ~10 days). Spread refresh across the watchlist by sharding
   on `hash(ticker) % 7` over the week to amortize.
5. **Backfill strategy.** Initial deployment needs a backfill of last-4-
   quarter snapshots per ticker for the calibrator's warm-up period. A
   one-shot script `scripts/fundamentals_backfill.py` writes the parquet
   files from yfinance's quarterly frames.

## 10. Summary

This proposal closes TauricResearch G4 by adding a sixth-from-fan-in
fifth-shipped analyst that respects the ADR-0002 Protocol contract,
honors ADR-0018 §D8 ("never trains, only infers"), and follows the
established Kronos pattern for graceful failure (with the appropriate
distinction that asset-class mismatch is structural and uses Protocol-None
abstain rather than zero-confidence view).

The single most important design choice is the **snapshot cache**:
fundamentals are quarterly data dressed up as a tick-rate signal in
the upstream TauricResearch implementation, and getting the refresh
cadence right (daily cron, parquet, 7d hard staleness) makes the
analyst essentially free on the hot path while keeping data fresh
enough to matter.

Ready for review.
