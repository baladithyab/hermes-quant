# Recon: PDR-2/3/4 seams (TrendVelocity / ConvergenceValidator / SaturationScore)

**Date:** 2026-05-31
**Scope:** the EXACT attachment points the ADR-0079 PDR-2/3/4 perception primitives plug into.
PDR-1 (PerceptionFrame carrier + adapter) is SHIPPED with EMPTY slots; this maps where each
primitive's output fills a slot and modifies the catalyst → semantic → BMA pipeline.
**Sources:** `docs/adr/ADR-0079-perception-decision-reaction-architecture.md`,
`docs/design/pdr-unified-architecture.md` §0–§4,§6; the files cited inline below.

---

## 1. PDR-1 carrier — where a primitive's output attaches + reaches analysts

- **`perception/frame.py:38-40`** — three EMPTY slots already declared on the frozen
  `PerceptionFrame`: `trend_velocity` (GAP-A), `convergence` (GAP-B), `saturation` (GAP-C), each
  `Mapping[str,Any] | None = None`, "empty until PDR-2/3/4". This is the typed home for each
  primitive's scored output; add-only, no shape change needed.
- **`perception/builder.py:191-203`** — `build_perception_frame` constructs the frame; today it
  hardcodes `trend_velocity=None, convergence=None, saturation=None` (lines 199-201). A primitive
  attaches here: compute it during construction (after the semantic slice, `builder.py:168-185`),
  pass the Mapping in place of `None`. The semantic slice (`builder.py:172-185`) is where
  packets are loaded via `load_packets_for` — PDR-2/3 must run **before/around** that so velocity
  sources the magnitude and convergence gates emission.
- **`perception/adapter.py:51-56`** — `frame_to_context` projects each non-None slot into
  `ctx.extras["trend_velocity"|"convergence"|"saturation"]`. PDR-1 leaves them unwritten when None,
  preserving the default extras key-set byte-for-byte. This is HOW a primitive's evidence reaches
  the analysts (they ignore unknown keys, `protocol.py:16`). **Note:** PDR-4's `saturation` reaches
  the semantic analyst via this extras key (`adapter.py:56`).

## 2. Catalyst pipeline the primitives feed/modify

- **`catalyst/ingest.py:28-45`** — `CatalystItem(title, published_at, source, link, query)`.
  `published_at` is the tz-aware UTC fidelity anchor → becomes `packet.asof`. `source` is the
  PDR-3 convergence key: GN-RSS sets the publisher (`ingest.py:130`); social sets
  `"reddit/r/<sub> (score=..)"` (`social.py:91`) and `"google_trends/<geo>"` (`social.py:185`) —
  these are the raw strings PDR-3's source-family taxonomy must normalize (reddit / google_trends /
  news / web-traffic) and police for shared upstreams.
- **`catalyst/classify.py:112-139`** — `classify_headline` IS the severity-on-KEYWORDS magnitude
  PDR-2 replaces. `severity = max single-term lexicon weight on the winning polarity side`
  (`classify.py:128-129`), a static word-boundary match on ONE title. Returns
  `Classification(polarity, severity, matched_terms, is_catalyst)`. No acceleration logic.
- **`catalyst/propagation.py:319-387`** — `propagate(entities, catalyst_sign, graph)`:
  confidence = noisy-OR linkage × directional agreement (`propagation.py:377-379`); stance from
  signed weight. `relation` tag `"brand_self"` (`propagation.py:143-147`) is the consumer-trend
  edge class. Unchanged by PDR-2/3/4; it produces the `PropagationResult` synthesize consumes.
- **`catalyst/synthesize.py:69-139`** — `synthesize_packets`: per item, `classify_headline`
  (line 91) → `extract_entities` → `propagate` (line 99) → one packet per touched symbol.
  Packet `confidence ← linkage×haircut` (line 106,115), **`magnitude ← round(cls.severity,4)`**
  (line 116). This `magnitude=cls.severity` line IS the PDR-2 swap point. The
  `CONSUMER_TREND_CONFIDENCE_HAIRCUT=0.5` seam (`synthesize.py:52-66,106`) is PDR-4-adjacent and
  PDR-3-adjacent (both modify the confidence path). `load_packets_for` (`synthesize.py:158-232`)
  collapses to best-per-stance (lines 220-232) — the place PDR-3 notes today multi-source signals
  are merely deduped, never validated.

## 3. Semantic analyst — PDR-4's pre-BMA multiplier point

- **`analysts/semantic.py:75-145`** — `HermesSemanticAnalyst.analyze`. `packet.confidence` →
  `confidence_raw` (line 88) → `confidence = max(0, raw - confidence_shrink)` (line 89) → a regime
  multiplier already applies pre-view (`semantic.py:124-130`, `apply_regime_multiplier`) → the
  `AnalystView(confidence=float(confidence))` is built at **`semantic.py:132-141`**. THIS is the
  exact spot PDR-4's `[SATURATE]` multiplier `m∈(0,1]` applies — read `ctx.extras["saturation"]`
  (delivered by `adapter.py:56`) and multiply `confidence` immediately after the regime multiplier
  (line 130), BEFORE the view is constructed (line 132). The regime multiplier is the existing
  precedent for a silence-only pre-BMA confidence adjustment on this same view.

## 4. Source families + the D74.7 eval gate PDR-2 reuses

- **`catalyst/social.py`** — the Reddit/Trends producers. Source-family tags PDR-3 keys on live at
  `social.py:91` (reddit) and `social.py:185` (google_trends); `ingest.py:130` is the news family.
  `ingest_social` (`social.py:222-247`) only `dedupe_items`-merges across producers — no
  cross-source validation today (the GAP-B PDR-3 closes).
- **`catalyst/eval.py:76-120`** — `run_precision` (the D74.7 directional-precision ≥0.6 hit-rate
  gate) + `eval_gate` (`eval.py:197-224`). It synthesizes packets and checks stance vs realized
  forward return. PDR-2 reuses this UNCHANGED: feed velocity-sourced-magnitude packets through
  `run_precision` to clear the same ≥0.6 bar. `ops/scripts/quant-catalyst-socialarb-eval.py`
  drives it against the 5 Camillo cases with real yfinance returns (passes graph/aliases explicitly,
  mutates nothing live) — the template the PDR-2/3 evals extend.

## 5. CLEANEST attachment point per primitive (file:line)

- **PDR-2 `TrendVelocity`** → produce in `builder.py` and source `packet.magnitude` from it. The
  load-bearing swap is **`synthesize.py:116`** (`"magnitude": round(float(cls.severity),4)` →
  velocity score). To thread velocity in, add a `velocity_by_symbol`-style optional arg to
  `synthesize_packets` (`synthesize.py:69-77`); compute the series in the new `perception/velocity.py`
  producer called from `builder.py` (alongside the semantic slice, ~`builder.py:168`), store the
  score in `frame.trend_velocity`. Eval via `eval.py:run_precision` unchanged. Flag
  `HERMES_QUANT_TREND_VELOCITY`, read at call time.
- **PDR-3 `ConvergenceValidator`** → gate packet EMISSION inside `synthesize_packets` at the
  per-symbol loop **`synthesize.py:100-108`** (before `packets.append`, line 138): require ≥2
  independent source families derived from the item set's `CatalystItem.source` strings
  (`ingest.py`/`social.py:91,185`); single-source → haircut/drop. A pure
  `perception/convergence.py` function over the `CatalystItem` set, with a policed family taxonomy.
  Result stored in `frame.convergence` (`builder.py`). Complementary to BMA's
  `require_ensemble` (`aggregators/bma.py:498-519`, cross-ANALYST). Flag `HERMES_QUANT_CONVERGENCE`.
- **PDR-4 `SaturationScore`** → compute in `builder.py` → `frame.saturation` → projected to
  `ctx.extras["saturation"]` (`adapter.py:56`) → applied as a multiplier on the semantic view's
  confidence at **`analysts/semantic.py:130-132`** (after regime multiplier, before `AnalystView`
  construction). View-level NOT aggregate-level (D79.4): never touches the non-semantic views fused
  at `advisor.py:1010` (`aggregator.aggregate(views, ctx)`). Property tests: post≤pre; non-semantic
  views bit-identical sat-on-vs-off. Flag `HERMES_QUANT_SATURATION`.

## Rails restated (every primitive)

Default-OFF, gate read at call time, flag-OFF byte-identical; perception-layer evidence only;
PerceptionFrame is a container not an authority; SaturationScore silence-only (post≤pre, same
boundary as catalyst-as-evidence + ADR-0077 admissibility); discrete ladder untouched; every
primitive stamps `asof`; external-truth eval (forward returns) via `eval.py`, never self-graded.
