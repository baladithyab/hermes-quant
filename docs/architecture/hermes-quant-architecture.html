hermes-quant Architecture

Multi-analyst BMA-aggregated trading system with research debate, risk gating, and reflective memory

v0.6.3 · 67 ADRs · CI green · 2,128 tests passing

Data flow contract

  • • Universe (yfinance, polygon, alpaca, ccxt) feeds OHLCV + fundamentals
  • • MarketContext envelope passed to every analyst — single source of truth
  • • extras["regime"] populated by HMM detector before analyst dispatch (ADR-0063)
  • • grounding/ stamps freshness + cite-or-die before LLM analysts touch it
  • • 5 analysts run in parallel: classical_ta, microstructure, semantic, kronos, fundamentals

Aggregation guarantees

  • • BMA requires N≥2 distinct analysts (anti-degeneracy guard from 2026-05-26 incident)
  • • Per-regime weights — bull-trend ≠ bear-chop weights
  • • Confidence shrinkage when regime-disagreement is high
  • • vote_share + consensus metric written into signal_provenance
  • • Alternates: deliberative (LLM) and llm_committee (multi-model)

Research Debate (v0.6.2)

  • • Bull/Bear conversational debate over BMA-aggregated signal
  • • Research Manager judges debate (cannot run blind — T11 regression test)
  • • Trader Node intermediary sets sizing and time-horizon
  • • Fully audited as research_debate kind with prompt_hash
  • • Flag-gated: HERMES_QUANT_RESEARCH_DEBATE=1 · default OFF

Risk + governance

  • • Pre-checks: confidence floor, data_quality (None-checked), cost_multiple, kelly cap
  • • 3-way risk committee round-robin: Aggressive / Conservative / Neutral
  • • Outputs Proposal with 24h TTL — HITL approves via approve <PROPOSAL_ID>
  • • Every gate event writes signal_provenance to audit_log
  • • Kill switch + invariants + lookahead_gate run silently (ADR-0031)

Execution + state

  • • PaperReactor + LiveReactor share base contract
  • • processed_fills(proposal_id, asof_execution) is UNIQUE — idempotent on crash
  • • executions.jsonl is canonical, state.db is derived cache
  • • state_reconstruction_failed audit event surfaces divergence
  • • state.db chmod 0o600, parent dir 0o700 — no world-readable financials
  • • BEGIN IMMEDIATE — write-lock-on-start eliminates read-then-write race

Memory + reflection

  • • decisions.jsonl snapshots every pre-trade reasoning bundle
  • • BM25 retriever surfaces relevant past decisions cross-ticker
  • • Post-trade reflector rubric: alpha vs benchmark, prediction error, lesson
  • • Oracle Fallacy guard test prevents self-justifying loops
  • • Shadow account counterfactual = backtest of rejected paths (Wave 8)
  • • 62 memory tests passing — module shipped, awaiting dogfood activation
