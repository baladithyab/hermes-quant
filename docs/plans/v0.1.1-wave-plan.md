## Why single-author for v0.1.1

The v0.1.1 surface is internally coherent: the signal bus contract, risk gate's
Kelly numerator, heartbeat protocol, halt registry SQLite schema, slippage
side-aware computation, and freqtrade strategy's bus reader all reference each
other's exact byte layouts. Splitting these across parallel subagents in a
"Phase 6 wave" would produce four implicit, slightly-different versions of the
JSONL field set (one with `target_position_pct: float`, one with `position_pct`,
one with `pos_target`, etc.). The orchestrator-author pass produces a coherent
surface in the same wall-clock with zero merge tax.

Per skill (`deep-work-loop`):
> When the backlog item is "establish a new internally-coherent vocabulary"
> (protocol, schema, framework abstractions), Phase 6 collapses to a single-author
> orchestrator pass; parallelism returns starting in the wave that EXTENDS that
> vocabulary.

v0.1.2+ (KronosAnalyst, MicrostructureLite, AlpacaProvider, NautilusTrader
consumer) are the parallelism-shaped follow-ups.

## Hard scope (P0 — must land in v0.1.1)

From CHANGELOG `Known v0.1.0 limitations` + synthesis-v2.md:

1. **Kelly numerator `(2p-1)·m`** — replace amended `p·m` (P0-A from v2 review).
   Implement `expected_log_return()` and `expected_signed_edge()`. Cost-gate AND
   sizer use `expected_signed_edge`. Unit tests with closed-form values.

2. **JSONL atomicity via `flock()`** — replace PIPE_BUF citation (P0-B). Both
   `signals.jsonl` AND `executions.jsonl` use `append_locked()` helper.
   Freqtrade strategy uses the same helper. Cap = 16384 bytes (our cap, not
   POSIX guarantee).

3. **Heartbeat bootstrap hole** — strategy enters safe-stop if `bootstrap_age >
   bootstrap_grace_seconds` (default 120s) and no heartbeat seen (P0-C).
   Backtest synthesizes per-bar heartbeat.

4. **Emergency-stop durable halt** — `hermes quant emergency-stop` writes halt
   FIRST (durable SQLite row), THEN broker cancel (P0-D). `--reason` required.

5. **SQLite halt PK NULL safety** — `'*'` sentinels for wildcard scope; columns
   `NOT NULL`; `WITHOUT ROWID`; `UNIQUE(account_id, asset_class, asset)` (P1-β).

6. **Slippage adverse-bps side-aware** — `buys = (fill - decision)/decision`,
   `sells = (decision - fill)/decision`, persist positive adverse only (P1-ζ).

7. **Daemon implementation** — `hermes_quant.daemon.main:main` runs the
   tick→analyze→aggregate→gate→emit loop + heartbeat emitter + settlement loop.

8. **ClassicalTAAnalyst** — RSI + MACD + Bollinger + MA-cross composite.
   Pre-calibration shrinkage `confidence = max(0, raw - 0.20)` per ADR-0002.

9. **BMAAggregator** — Bayesian model averaging across analyst views with
   per-analyst posterior weights from `RealizedOutcome` history. Fallback to
   uniform weights pre-calibration.

10. **RiskGate (concrete)** — implements ADR-0004 §Decision sequence with
    synthesis-v2 fixes. Cost gate uses `expected_signed_edge`; Kelly sizer
    uses `expected_signed_edge / σ²`.

11. **yfinanceProvider** — equity OHLCV fetch with provider-chain fallback,
    OHLCV validation gates per `MarketContext` invariants.

12. **Freqtrade consumer strategy** — `quant_consumer_strategy.py` with bus
    reader, halt handling, stale-signal guard, dead-man-switch (heartbeat
    bootstrap fix), `executions.jsonl` back-channel (uses `append_locked`).

|---|---|
| Kelly fix introduces backtest regression vs v0.1.0 placeholder | v0.1.0 had no daemon — no regression to compare. New baseline. |
| flock semantics differ on macOS vs Linux | `fcntl.flock` is POSIX; tested on Linux (CI). macOS uses BSD flock semantics — same syscall path. Document in AGENTS.md if any divergence surfaces. |
| yfinance rate-limits during test | Mark as `requires_network`; default skip in CI; manual run before tag. |
| Subagent self-reports "tests pass" but bridge layer doesn't actually wire | Wave 3 includes integration tests that exercise the wired surfaces, not just unit tests against mocks. ## Post-mortem prompt (Phase 4 lite)

*Assume v0.1.1 shipped and silently lost user money in production. Write the
post-mortem.*

Most-likely root causes (mitigated by this plan):
1. **Heartbeat bootstrap hole** → P0-C fix above. Mitigation tested.
2. **Concurrent JSONL write corrupts a record at exactly the byte boundary that
   makes the consumer parse an old field as a new field's value, sending a buy
   with a sell's target_position_pct.** → flock + 16384-byte cap + JSON-shaped
   only writes (no partial writes possible inside flock). Mitigation: tested.
3. **Kelly overbet from `p·m` numerator persisted from v2 amendment** → P0-A
   fix above. Mitigation: closed-form unit tests.
4. **Halt state lost on daemon restart** → SQLite durable store (synthesis-v2
   §P0-D ordering: halt FIRST, then broker cancel). Mitigation: tested.
5. **Slippage adverse-bps with wrong sign on sells double-counts cost** →
   P1-ζ fix. Mitigation: symmetry test.

Bugs the plan does NOT mitigate (acknowledged):
- Calibrator drift undetected → `quant_doctor` surfaces calibration table; user
  is expected to monitor.
- Network partition between daemon and freqtrade → dead-man-switch handles by
  flattening; no opportunity loss but capital is preserved.
- yfinance returns wrong-asset bars on ticker collision → validation gates
  partially mitigate (sort, dedup, NaN-drop); ticker normalization is
  per-provider best-effort.
- RL aggregator gaming → out of scope; deferred to v0.2.0 (ADR-0006).

These caveats land in CHANGELOG as known limitations.
